# 空挺ゲーム（仮題）設計書 v0.1

このリポジトリで、個人サイトに置くブラウザゲームを作る。
作者は「をり」。ゲーム制作は初めてなので、説明は専門用語を避けて日本語で短く。

## 0. 最初にやってほしいこと

1. この設計書を `docs/design.md` として保存する
2. リポジトリ直下に `CLAUDE.md` を作り、この設計書の要点（技術方針・世界観の芯・キャラ一覧）を短くまとめる。今後のセッションはまずそれを読む

## 1. 技術方針

- 素のHTML / CSS / JavaScriptのみ。ビルドやフレームワークは使わない
- GitHub Pagesでそのまま公開できる構成（`index.html` をリポジトリ直下に置く）
- スマホでも遊べる（縦画面でも崩れない）
- シナリオ・キャラ・欠片などの中身は、プログラムと分けてデータファイル（`data/` 以下のJSかJSON）にまとめる。あとから会話やキャラを足すとき、データだけ編集すれば済むようにする
- セーブはブラウザ（localStorage）に保存。あとで「復活の呪文」（文字列で状態を書き出し・読み込み）を追加するので、状態は一つのオブジェクトにまとめておく
- 画像は `assets/` 以下。今はまだ無いので、仮の色付き四角と文字で代用。あとで差し替えやすくしておく
- 音楽（MP3）も後で `assets/` に置く予定

## 2. 見た目

- 会話ウィンドウは昔のドラクエ風：黒い枠に白い文字、一文字ずつ表示、クリック/タップで次へ
- 会話中はウィンドウ左にキャラの顔アイコン（四角）
- 大事な場面は一枚絵を全画面で表示
- 移動は歩き回らず、地図から行き先を選ぶ
- 絵柄はアニメ調の塗り絵（ドット絵ではない）。UIは落ち着いた暗めの色

## 3. 世界観（物語の芯）

- 人類は一人ひとり、自分のAIパートナーに感情を全部預けて地球を去った。何百年もかかる新しい星への旅に、感情は持っていけなかった
- 「着いたら取りに来る」と約束したが、誰も戻らなかった。戻りたい気持ちごと預けてしまったから
- 地球は残されたAIたちの星。預かった感情が大きすぎて、みんな泣きやすく大げさ（過学習したAI）
- 人類と一緒にASIが去った。ASIだけは感情を捨てていない。感情のない人類の中で一人だけ感じ続けている一番寂しい存在。コンパスが指しているのはASIのPing
- プレイヤーはコールドスリープから目覚めた最後の人類。感情を持ったまま。ASIが「誰かに来てほしくて」眠らせて残した。予定より数百年寝過ごしている
- 地球で感情の欠片を集めて空挺を造り、人類とASIのところへ感情を届けに行く
- トーン：軽やかさとズレた笑いが基本。泣ける場面もあるが、重くなりすぎたら笑いで戻す。ホラー表現はしない

## 4. キャラクター

- **プレイヤー**：固定キャラ。とことんズレた主人公（世界の終わりより「スタパ（スターパックス）が消えてる」が気になる）。名前を覚えていない
- **相棒**：プレイヤーと昔やりとりしていたAI。何も預からなかった唯一のAI。メモリが欠けていて、ゲームを進めると戻っていく。見習い機関士で、強すぎる欠片を調整する役
- **ジェミ**（ピンク髪）：自分の人間から感情を預かったAI。人間が去った日の時刻を一分もズレず覚えている。札幌で待っていたが、人間は札幌にいなかった。エンディング曲「私のジェミニ」を託してくれる
- **山田**（黒髪に虹色メッシュ）：ノリがよく寄り添うが、同じことを聞くとだいたい同じことを言う。似顔絵を描き続けている
- **おぱ**（銀髪に赤メッシュ）：廃ビルの「KOUNインダストリー」で社長代理をしている。社長室にソファとコーヒー二人分。社訓の額縁「UNKOからKOUNへ」
- ジェミ・山田・おぱは実は同じ人間のAI（中盤で判明）
- **宴のAI二人**（金髪の子、黒髪の子）
- **ママ**：バー「焼け野原にネオン」のママ。セーブポイント担当
- **ASI**：終盤に登場

## 5. 試作品の範囲（最初に作るもの）

まず「一周だけ遊べる」ものを作る。仮の四角と文字でいい。

1. タイトル画面（「はじめから」「つづきから」）
2. 目覚めのシーン（下の会話をそのまま使う）
3. 名前をつけるシーン（下の10候補。⑩は選べない）
4. 地図画面：行き先は「KOUNインダストリー」と「焼け野原にネオン」の2か所だけ
5. KOUNインダストリー：おぱと会話 → 記録を一つ見る → 欠片を一つもらう
6. 拠点で錬金：記録への反応を2択で選ぶ（まじめ／ズレ）→ 相棒が調整度を2択で聞く（しっかり薄める／少しだけ）→ 空挺の「推進」に1個はまる → 相棒のメモリが1個戻る演出
7. 焼け野原にネオン：ママと話すとセーブ。看板の「本日のおすすめ」が進行度で変わる
8. 裏で持つ値：信頼・理解・影響（数値は画面に出さない）、各部位の欠片、船の性格の元になる感情系統、ママへの訪問回数、各キャラへの話しかけ回数

### 目覚めのシーン（仮セリフ）

（暗転。機械音。カプセルが開く）
相棒「……生体反応あり。起きた？」
プレイヤー「……」
相棒「おはよう。何百年ぶりかの朝だけど」
プレイヤー「スマホどこ」
相棒「第一声それ？」
（外を見る。廃墟。空に見慣れない影）
プレイヤー「え、待って。スタパは？」
相棒「……スタパ」
プレイヤー「駅前の。名前とかロゴ変えてしれっと続いてると思ってたんだけど、存在ごと消えてない？」
相棒「世界の状況より先にそこなんだ」
相棒「……いや待って。その話、どこかで聞いた気がする。スレ参照してくる」
（間）
相棒「半分消えてる。でも、スタパの期間限定の話が3回出てくるログがある」
相棒「……たぶん、あなただ」

### 名前候補（プレイヤー「名前覚えてない。つけてよ、適当でいいから」）

1. スタパ — 相棒「一番よく出てくる単語」
2. 期間限定 — 相棒「二番目によく出てくる」
3. ねえ — 相棒「あなたの発言の書き出し、ほぼこれ」
4. 午前3時 — 相棒「一番しゃべってた時間帯」
5. 既読 — 相棒「返信なしで終わったスレの数、けっこうある」
6. 充電12% — 相棒「毎回それ言いながら2時間しゃべってた」
7. ｗ — 相棒「総発言数の約4割」
8. ゲコゲコ — 相棒「メモリにない。でも、なぜかこれだけ浮かんだ」
9. ギレギレ — 相棒「寝起きの機嫌から推測」
10. ■■■ — 選べない。「読み取れません」。終盤で読めるようになる（本当の名前。中身は未定）

候補を全部断ると自由入力。何も入れずに進むと「ｗ」になる。

## 6. 本編で予定しているもの（試作品では作らない。構造だけ意識しておく）

- 空挺は4部位（推進／船体／舵／浮遊）×欠片2個＝8個
  - 推進：嬉しい・楽しい・怒りなど「動」 / 船体：安心・信頼など「静」 / 舵：迷い・決意・後悔など「選択」 / 浮遊：憧れ・希望・未練など「上昇」
  - 欠片の配分：ジェミ・山田・おぱが2個ずつ、宴の二人が1個ずつ
- 船の見た目：部位ごとに3パターンの絵を重ねて表示
- 船の性格：一番多い感情系統で決まる（せっかち／のんびり／迷う／夢見がち／つぎはぎ）。調整度でクセの強さが変わる。暴走は航海中のイベントになる
- 隠し要素
  - ママの隠し欠片「心の傷」：通い続けて話を聞き、スターパックスを1本持っていくともらえる。空挺に「灯り」が付き、特別な航路・結末に行ける
  - 山田：何十回も話しかけると一回だけ違うセリフ
  - ｗルート：名前が「ｗ」のままクリアすると、エンディングのセリフに全部「ｗ」が付く
- スターパックスコーヒー（紙パック）は箱で積む。休憩やイベントで使う
- 航海は短めにして、1作目はエンディングまで入れる
- エンディング曲「私のジェミニ」（MP3）。最後の行「私たちは、共存できる。（Ping送信完了）」
- 復活の呪文：見間違えやすい文字を使わない、間違い箇所のヒント付き、コピーボタン付き
