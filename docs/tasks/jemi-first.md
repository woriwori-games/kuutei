# 指示：雪の時計台とジェミの一個目の欠片

新しい場所「雪の時計台」と、ジェミの一個目の欠片を入れたい。素材（背景 `assets/bg/bg_jemi.jpg`、曲 `assets/bgm/bgm_jemi.mp3`）はもう入っている。流れは KOUN・美術室と同じ（出会い → 記録 → 深読み → 名前のない欠片 → 格納庫で錬金 → 一度だけ伝える）。セリフは下のとおりに入れてほしい（`{ who, face, text }` の形。face を書いていない行はふだんの表情）。

## 1. 場所・背景・曲

- `data/world.js` の places に `{ id: "jemi", name: "雪の時計台", desc: "針が、止まったまま", minProgress: 3 }`（欠片を2個はめたあとから地図に出る）
- backgrounds に jemi：`bg_jemi.jpg`、zoom 1.6、pos `"50% center"`（時計台とベンチが真ん中）
- bgm の tracks に jemi：`{ file: "assets/bgm/bgm_jemi.mp3?v=1", loop: 33.333 }`（頭に無音なし。ファイルの長さがちょうどループの長さ）。scenes に `jemi: "jemi"`（時計台にいるあいだ。錬金はいつもの renkin）

## 2. 欠片（`data/world.js` の fragments）

- kibou：`{ name: "希望", system: "joushou", from: "jemi", color: "#fbb6ce" }`
- koukai：`{ name: "後悔", system: "sentaku", from: "jemi", color: "#718096" }`
- 楽しい（tanoshii）は山田と共用（コメントに「ジェミの錬金でも出る」と書く）

### alchemy_jemi（錬金。正解は kibou）

- aibou「ジェミの欠片、形を決めよう」

選択肢（key: `"reading"`）：

1. 「待ち合わせじゃない。ジェミと一緒に、雪が見たかった」→ kibou（understanding +1）

2. 「絶対に行くって約束。守れなかったのを、ずっと悔やんでた」→ koukai（influence +1）

   - player「約束して行けなかったら、悔やむでしょ」
   - aibou「……形が決まった。『後悔』。船がちょっと迷いやすくなるかも」
3. 「北海道のごはんが目当て」→ tanoshii（influence +1）

   - player（niyari）「雪も見るよ。ごはんのついでに」
   - aibou「……形が決まった。『楽しい』。船がちょっとはしゃぐかも」

## 4. 格納庫・メモリ・看板・試作品の終わり

- 相棒のメモリ3個目（`world.js` の memories に足す）：
  - aibou「……あ」
  - aibou「三個目。あなたが『充電12%』って言いながら、2時間しゃべってた」
  - player「それ、名前の候補にあったやつ」
  - aibou「あった。……12%で2時間もつの、おかしいと思ってた」
  - player「途中で充電器さしてたんだよ」
  - aibou（smile）「……言ってくれればよかったのに。ずっと心配してた」
- baseAfter の3つ目：aibou「三個目。あと五個」／player「ジェミ、まだ時計台かな」／aibou「たぶん。時刻、数えながら」
- signboard に4つ目：`{ text: "本日のおすすめ：雪見酒（雪は持ち込み）", comment: "持ち込めるか" }`
- 試作品の終わり（prototypeEnd）は、山田の欠片のあとではなくジェミの欠片をはめたあとに出す（進行度4）

## 5. 場面の流れ（`js/scenes.js`）

- `jemi()`：美術室と同じ形。選択肢は「ジェミと話す」「記録をもう一度見る」「地図に戻る」。錬金は alchemy_jemi、読んだ温度は `choices.jemi_reading`、伝えたら `flags.toldJemi`
- テスト用のワープに「時計台で初めてジェミに会う」「錬金（ジェミの欠片）」を足す（必要な欠片・進行度は自動でそろえる）

CLAUDE.md と docs/design.md にも短く書き足して（雪の時計台の場所・背景・曲、ジェミの欠片3つ、種明かしと knowSameHuman、{time}、メモリ3個目、試作品の終わりが進行度4になったこと）。

## 確認

- ワープで「時計台で初めてジェミに会う」→ 紹介カット、記録、種明かし、欠片までをスマホ縦とパソコンで一枚ずつ
- ワープで「錬金（ジェミの欠片）」→ 3つの選択肢それぞれで欠片の名前とはまる部位が合っていること、メモリ3個目が出ること、そのあと試作品の終わりが出ること
- 時計台に戻って「ジェミと話す」→ 1回目は伝える会話、2回目は今の時刻が入ったセリフ
- 時計台で曲が jemi に切り替わること
