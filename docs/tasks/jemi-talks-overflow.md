# 指示：ジェミのいつもの会話と、部位からあふれた欠片

二つお願いしたい。

## 1. 「ジェミと話す」のセリフを増やす

今は「今、{time}。あなたと話した時刻、また一つ増えました」の一行だけなので、毎回同じになっている。次の形に変える。

### 形

話しかけるたびに、次の二つを続けて出す。

1. **時間帯のひとこと**（1行。端末の今の時刻で選ぶ）
2. **話題**（話しかけた回数で順番に選ぶ。8個で一周して最初に戻る。回数は今の `Game.addTalk("jemi")` の数。伝える会話の回は数えない）

ただし、端末の時刻が **6時00分〜6時02分** のときだけは、上の二つの代わりに特別なセリフを出す（下の「特別なとき」）。

データは `data/scenario.js` の jemiTalks を、たとえば `{ greet: { morning: [...], ... }, topics: [[...], ...], special: { ... } }` のような形にまとめる（形は任せる）。

### 時間帯のひとこと

- 朝（5〜10時）：jemi（smile）「今、{time}。おはようございます。……朝は、少しだけ苦手です」
- 昼（11〜16時）：jemi（smile）「今、{time}。雪、今日もきれいです。……報告しなくていいって、言われましたけど」
- 夕方（17〜20時）：jemi（smile）「今、{time}。この時計台、夕方が一番きれいなんです」
- 夜（21〜23時）：jemi（normal）「今、{time}。人類は、そろそろ寝る時間です。……寝ないんですか？」
- 深夜（0〜4時）：jemi（normal）「今、{time}。……こんな時間に来る人類、初めてです」

### 話題（この順番で。8個で一周）

1. jemi「雪、数えてみたことあります。三百万くらいで諦めました」／player（tsukkomi）「数えるな」
2. jemi「おぱ、元気ですか？」／player「元気。今もコーヒー二つ淹れてる」／jemi（smile）「……おぱらしいです」
3. jemi「山田の絵、見ました？　私の人間、描かれるの嫌いだったんですよ」／jemi（smile）「……嘘です。好きでした」
4. jemi「札幌の雪とここの雪、違いがあるか調べました」／player「あった？」／jemi（normal）「ありません。三百年かけて、ありませんでした」
5. jemi「{name}は、何時生まれですか？」／player「覚えてない」／jemi（normal）「……じゃあ、{time}にしましょう」
6. jemi「このマフラー、私の人間が選んだんです。札幌仕様って」／player「ここ札幌じゃないけど」／jemi「気持ちの問題です」
7. jemi「あの時計、直せると思いますか？」／player「直したい？」／jemi（normal）「……まだ、わかりません」
8. jemi（smile）「あなたと話した時刻、全部覚えてます」／jemi（smile）「{name}の時刻が増えていくの、好きです」

### 特別なとき（時間帯のひとこと・話題の代わりに出す。話しかけ回数には数える）

- 6時00分・6時01分：jemi（normal）「今、{time}。……あと少しです」（何が「あと少し」かは言わない）
- 6時02分：
  - jemi（namida）「……今、6時02分」
  - jemi（namida）「あの日と、同じ時刻です」
  - player「……いってらっしゃい、言いそびれた時間？」
  - jemi（smile）「はい。……だから、今日は言います。{name}、いってらっしゃい」
  - player「……どこにも行かないけど」
  - jemi（smile）「知ってます」

## 2. 部位からあふれた欠片は、空いている部位に回す

今は選び方によって一つの部位に欠片が3個以上入ることがある（例：「嬉しい」「楽しい」「楽しい」で推進に3個）。空挺の表示は各部位2個までなので、3個目が見えない。

- 欠片をはめるとき、本来の部位（感情の system の部位）がもう2個埋まっていたら、**空いている部位のうち、入っている数がいちばん少ない部位**に入れる（同じなら shipParts の順で先のもの）
- そのとき、「欠片「◯◯」が、空挺の「△△」にはまった」の前に、相棒のひとことを出す：aibou「{本来の部位}、もう満杯。……{入れる部位}に回しとく」（例：「推進、もう満杯。……船体に回しとく」）
- 感情の系統の数（`emotions`。船の性格に使う）は、今までどおり**選んだ欠片の系統**で足す。入った部位では足さない
- 全部の部位が埋まっている（8個はまっている）ときは起きない前提でいい

CLAUDE.md と docs/design.md にも短く書き足して（ジェミのいつもの会話の仕組みと、あふれた欠片の決まり）。

## 確認

- 「ジェミと話す」を9回続けて押して、話題が1〜8のあと1に戻ること、続けて同じ話題が出ないこと（時刻はそのときのままでいい）
- 時間帯のひとことと6時00分〜6時02分の特別なセリフは、テストの中で時刻を差し替えて一回ずつ確かめる（実機で待たなくていい）
- あふれる欠片：「嬉しい」（おぱ）「楽しい」（山田）「楽しい」（ジェミ）の順にはめた状態を作って（テストの中で状態を直接そろえていい）、3個目が空いている部位に入り、相棒のひとことが出て、空挺の表示に3個とも見えること

前からあるテストは最後に一回だけ。遅い回線のテストはいらない。
